# 知基 · 我的基金

本地、单用户、使用免费公开资料的基金买卖决策工具。输入基金代码，选择“还没买”或“已经持有”，再选往后看1–90个自然日，一次只看对应的一条操作建议：现在怎么做、主要原因、什么时候再考虑。当前页不要求真实金额、总资产或研究API，也不展示示例本金、金额差、个人资金规划、模型选择器或研究辩论；真实净值历史与计划期末涨跌估计分成两个面板，完整研究和可选计算工具放在“走势与资料”。建议依据经营、回款、资金占用和当前价格的经济取舍；未验证的预测均值及微小费用后差额不能自动改成买入或卖出。模型仍在验证，明确建议不等于已经证明有盈利优势。

它不会连接支付宝、券商或其他金融账户，不会替你买卖，也不会上传持仓。个人持仓只在你明确保存时写入当前工作区的独立本地文件。

## 日常使用

```bash
uv sync --group dev
.venv/bin/rmbfund --root data/ui-preview-20261020-v1 --mode public ui
```

打开 <http://127.0.0.1:8501>。服务只监听本机；远程查看使用SSH本地转发：

```bash
ssh -L 8501:127.0.0.1:8501 用户@服务器
```

首页操作边界：

- 首页直接按代码查看公开判断，不必添加个人持仓。当前情境用“还没买／已经持有”轻量切换，一次只展示所选情境；已有情境的假设买入净值日、份额确认日和费率在“日期与费用设置”调整，不把假设记录当成真实持仓。
- “计算本周期判断”是当前页唯一的显式本地计算入口，只用已有资料计算准确的净值期限并在内存缓存，不联网、不调用研究API、不发行预测或评分。自然日窗口按明确日程映射为预计净值笔数，不把20笔叫20天或插值概率；只复用相同期限H、起点延迟L及输入的缓存，缺准确预测头就留空，等明确点击才算。编辑费用只重算费用情景，不拟合模型或改写经济建议。
- 添加真实份额和剩余持仓成本只在本机保存，市值与浮盈亏留在个人总览和管理工具，不置于当前建议首屏。个人金额换算与资金规划在“走势与资料”的可选工具中，不是基金判断或保存的前置条件。
- 普通打开当前判断、总览、走势和历史均不自动联网，也不自动拟合、调用研究API或评分。当前判断先用本地资料或本会话已有上下文；明确点击“重新在线检查”才刷新公开净值与定向资料，点击已配置的“更新研究”才运行对应取材和研究流程。响应可直接在内存解析使用，不要求先下载或导入；改费用、期限、情境、切页或保存不会重复请求。
- “刷新估算”单次读取选定免费来源；“每分钟检查”默认关闭，开启后只检查当前基金。切基金、切来源、离开走势页或取数失败会停止自动检查。60秒内共用一次结果，不承诺来源每分钟更新。当前判断的在线净值与公告是另一条会话内复用路径，不写入正式净值或研究库。
- “最近估算”接入基金速查网与持仓记录助手公开数据，保留来源原时间。018147曾取得基金速查网的非空旧估算；持仓记录助手没有该C类，不替换成A类。尚未验证交易时段持续更新，因此不标为实时行情。
- 当前主流程固定使用原默认净值模型`nav_ridge_empirical_v2`，不再提供模型选择器。管理工具中的更新按钮仍需明确点击；“用已保存净值更新预测”不联网，“更新净值与预测”才获取公开输入并更新。投资因素和风险增强候选保留为独立研究能力，不自动晋级或替换默认方法。
- “保存这次判断”捕获刚才展示的同一份完整schema7 assessment，不在点击后另算一份。当前策略为`fund_buyer_economic_advice_v3`／brief schema3；保存所选`selected_branch`、该分支的`buyer_view`和同源`forecast_chart`，同时保留原研究、日期、分批费用、准确预测头与模拟参照。brief3历史直接回放存储的view和图，不重新构建，也不拿今天净值补画；缺失就说明未保存。旧brief1/2及assessment schema3–6仍按各自原语义字面回放，不补今天的动作、日期或费用。保存不代表提交买卖，本地RAM计算不冒充公开发行。
- “走势与资料”保留“运行历史检验”和“比较这几个卖出时点”。前者检验对应净值笔数，不冒称严格自然日策略或连乘重叠窗口收益；后者只比较同一笔旧份额的现在A、窗口内下一低费档对应开放日D、原计划卖出日S，去重而不搜索全局最佳日。缺准确期限需明确点击才本地计算；节费边界不是必须等待指令。这些核查与金额表不占用当前建议主屏。
- 当前判断只读对照本基金最近保存快照，优先呈现所选情境的动作、主要理由或条件的少量变化。新标题、取得时间或模型微差不自动构成改判；没有明确接续说明，不把新研究自行解释成旧理由失效。
- 历史中的schema7可另记计划、模拟采用、用户自述行动或观察；笔记只在明确保存时追加，真实记录时间与填写的发生日期分开。点“用已有净值查看这次模拟结果”只核对原固定模拟，不联网、拟合、改原判断、改持仓或增加发行成绩；自述行动不变成个人账户收益。
- 正式净值与最近估算分开，持仓市值仍按最近公布净值估算；估算不入库、不改变模型。
- 个人份额、成本、费用及判断快照不进入公开净值、预测输入、来源请求、研究报告、日志或模拟账户。

## 更新基金研究（模型API或明确会话追加）

“重新在线检查”只取得公开事实；“更新研究”才调用你已有的模型API，把经营、估值、政策、披露组合与替代选择整理为新买、保留、追加的不同论据。费用、份额、成本与预算不发送给模型。普通打开、切页、改费用或保存判断不会重复调用API；API使用你已有服务的额度，公开数据仍使用免费来源。

在当前判断的“研究API设置”中填写服务地址、模型名和Key即可。Key只留本次会话；服务端也可明确设置`RMBFUND_RESEARCH_API_KEY`。程序不会搜索其他终端的凭据或读取`.env`。目前客户端支持显式选择OpenAI兼容Chat Completions或Anthropic Messages协议，不自动猜服务商、协议或模型。

也可把[`configs/research-api.example.json`](configs/research-api.example.json)的非秘密字段填好，保存为工作区下`research-api.json`。`base_url`填写你已有服务的API根地址或与所选协议相符的完整`chat/completions`／`messages`地址，`model`填写该服务的实际模型名；**Key不写进这个文件**。命令行复用同一研究路径：

```bash
.venv/bin/rmbfund --root data/ui-preview-20261020-v1 --mode public research-update open_fund:018147:C
```

生成结果明确标为AI研究，不冒称人工审核。有采用的原文摘录、页/节定位和程序计算依据，不要求先把网页/PDF全文入库。API失败、引用不匹配或未配置时不出具硬编码替代意见，原研究保留原日期。程序能核对引用和计算口径，不能据此证明投资结论正确。

本轮另有**显式会话作者追加入口**，与模型API调用分开：

```bash
.venv/bin/rmbfund --root <已登记该基金的公开工作区> --mode public research-session-import open_fund:018147:C <会话研究.json> --evidence <实际采用的证据与计算包.json>
```

此命令只接收研究contract schema2、`origin.provider=interactive_assistant`的既有会话研究，按实际采用的摘录、定位和计算包完成绑定后追加版本与真实导入时钟；已经绑定的研究可省略`--evidence`。它不请求模型API、不替作者生成新结论、不拟合预测，也不覆盖旧研究或旧判断。研究contract schema2与当前展示用brief schema3是不同协议，不应混同。

## 页面会显示什么

1. **我的基金总览**：你添加的基金、市值与浮盈亏；首次打开不把018147或研究样本当成你的持仓。成本空白不按0，汇总保留实际覆盖范围。
2. **当前判断**：轻量切换“还没买／已经持有”，看所选情境的一条操作建议、一两句主要原因和下一步；下方两面板分别展示实际公布净值与准确H/L对应的计划期末涨跌估计，不编未来连续净值路径。观察截止日从实际测算日起算，不是必须清仓日；费用和已有情境的假设买入日在设置内。没有示例本金、金额差、个人规划、模型选择器、原始JSON、来源状态表、长消息列表或多方争论。只选取少量可读依据和简短变化，不按未验证均值重排经济动作；缺准确预测头不等于真实禁买，真实申赎暂停另行说明。
3. **可选组合与金额工具**：在“走势与资料”查看已记录且可估值人民币基金的比例、披露发行人重合和未覆盖部分；可选填现金、最高投入、损失预算与同一压力情景，计算条件买入上限或最低减少额。金额上限不等于建议用满；当前市值不等于已确认可赎金额，不影响当前页的基金经济建议。
4. **走势与资料**：保留原已公布净值走势图、主动刷新的最近估算，以及带日期和来源的经理、投向、公开持仓与披露费率；完整研究、公司经营与条件计算、历史检验、少数卖出日期比较和个人工具在此核查。默认NAV模型与独立经营／估值计算分开，不因为隐藏技术界面就省掉assessment后台分析。
5. **历史记录**：brief3直接回放保存时所选情境的`buyer_view`与`forecast_chart`，不重新build、不取今天的数据补画；旧brief1/2和schema3–6保持原展示语义。原量化发行另列，可选笔记不改快照；显式复盘只用已有NAV、原anchor、准确L/H、原本金／费用与原参照算固定模拟。历史重建、真正发行成绩、保存选择的模拟复盘三条轨道分开；自述不是已核实成交，零成绩不显示虚构准确率。

## 持仓口径

- 份额填写“现在确认还持有的份额”。
- 成本填写“目前剩余这些份额对应的总买入成本（人民币）”，不是当前市值、历年累计投入或账户终身收益。
- 空白表示不知道，0表示明确为0；不会用今天净值反推份额。
- 市值 = 份额 × 最近相容单位净值。账面浮盈亏 = 市值 − 剩余持仓成本；成本为0时不计算收益率。
- 非人民币净值不会直接与人民币成本换算或混加。
- 移除基金只删除当前个人持仓条目；已主动保存的判断快照、公开净值、预测和研究档案仍保留。

## 公司经营与估值
