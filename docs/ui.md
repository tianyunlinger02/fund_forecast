# 我的基金 · 本地界面

## 启动

```bash
.venv/bin/rmbfund --root data/ui-preview-20261020-v1 --mode public ui
```

打开 <http://127.0.0.1:8501>。root决定你使用的公开资料库和个人持仓文件；默认`data`与上述预览目录不是同一个工作区。服务只监听127.0.0.1，远程访问用SSH本地转发。

程序升级后，应停止旧服务，再用同一root、模式与端口重新启动；刷新浏览器不能保证旧进程里的Python模块一起升级。`rmbfund ... ui`会把源码目录加入Streamlit的监听范围，避免只重载页面、却继续调用旧版业务模块；正式升级仍以重新启动为准。重启本身不更新净值、不发行预测，也不修改持仓。

右上角“⋮”菜单可选择浅色（Light）、深色（Dark）或跟随系统（System）；这是显示设置，不是研究或交易入口。

## 第一次使用

在首页直接输入基金代码，点“公开预览”即可看当前建议，不要求先添加个人持仓、填写真实金额或配置研究API。在“当前情境”选择“还没买”或“已经持有”，调整“往后看几天（自然日）”，一次只看所选情境的一条最终建议、主要原因、下一步和净值历史／期末涨跌估计。当前页不展示假设1万元、金额差或整张操作比较表，也不让用户先选预测模型。可以另点“添加基金”记录真实份额和成本，已登记的基金复用实际份额类别，不把C类另建成无类别产品。私人库不可读也不阻断按代码研究，个人列表不会自动导入研究样本。

个人持仓独立保存在`<root>/personal-public.sqlite3`，演示空间使用`personal-demo.sqlite3`，二者不混用。打开不存在的工作区不会创建目录；首次明确保存个人记录才创建私有文件，首次明确更新公开数据才创建公开资料库。

## 份额、成本和盈亏

- **剩余份额**：现在已经确认、仍持有的份额，不包括尚未确认的申请。
- **持仓总成本（人民币）**：目前这部分剩余份额对应的总买入成本，不是历年累计投入，不是当前市值。
- **市值**：按最近已公布且币种相容的净值估算，不是当前可成交/可赎回金额。
- **账面浮盈亏**：估算市值减剩余成本，未扣赎回手续费，不含以前卖出和现金分红。

不知道可留空，空白不等于0。零成本不计算百分比收益。资料不完整时，概览数字各自显示覆盖多少只基金，盈亏只统计资料齐全的同一组，不把未知项目补零；非人民币净值不直接混算。

更正持仓或本机显示名称需要点击“保存持仓”；刷新公开资料不覆盖你的显示名。切换基金时同时显示代码与已知份额类别，避免同名A/C类混淆。移除需要确认且只删除当前个人持仓条目，已主动保存的私人判断与公共数据仍保留。

## 当前判断、走势与资料

基金详情默认先显示“当前判断”。公开预览和已登记持仓都先由用户选择“还没买”或“已经持有”，不根据示例金额或是否填写份额猜测情境。首屏主控是“当前情境”和“往后看几天（自然日）”（1–90天，默认30天）；天数用于考虑操作和复核，不是固定持有期，也不要求到期卖出。“日期与费用设置”中可调整模拟确认日期与四种费率；“已经持有”情境还可选择真实存在的假设买入净值日。个人金额换算、资金规划和完整研究不放在当前主卡。

进入这个标签会在线检查当前公开净值与定向消息，响应在内存中解析。本会话日期、费用、周期和页面编辑复用同一批结果，明确点击“重新在线检查”才重新检查仍可访问的来源。总览、走势和历史不触发这项检查。“计算本周期判断”只用已有完整来源／事件标记输入在RAM计算缓存，不联网、不调用研究API、不发行或评分。缺少对应预测时仍保留已有研究和保存能力，不用其他期限或更有利延迟代替。

### 当前页只给所选情境的一条建议

主卡直接显示最终动作、一句主要原因、下一步和一条简短的参考净值日期；不是同时展示两个情境供用户裁决，也不显示假设本金、备选金额差、模型ID、原始JSON或来源状态表。“这次判断的依据”只补充少量与所选建议相关的已保存事实、研究日期与公开引用；完整研究、反方、比较、资料检查与条件计算移到“走势与资料”的独立工具，不再以折叠辩论卡充当当前建议。

当前采用`decision_brief.schema_version=3`、policy `fund_buyer_economic_advice_v3`。最终动作来自已采用的经营／价格研究及明确的个人或执行约束；短期净值估计只是情景参考，不因未经验证的均值金额差、全表排名或旧作者补充的“同向／反向”标签自动翻转建议。已有份额与追加的研究取舍仍分别保留，减仓不自动等于卖50%。展示层只投影brief中所选分支已经确定的动作、原因、下一步、执行状态与数据日，不再次决定买卖或拟合模型。

原经济方向、最终建议、申赎执行状态和测算可比性分别保存在完整对象中。窗口过短、H=0或新确认日晚于计划日是测算缺口，不等于真实暂停申赎；真实暂停时才说明相关操作暂不能办理。研究过期或尚未形成充分依据时，明确给出待核对事项，不假装已经完成研究。观察条件不是自动交易规则，也没有关闭页面后的监控或推送。

### 真实净值线与单个计划期末估计

“净值历史与计划期末估计”使用上下两个独立面板：上图仅画实际已公布的单位净值及其真实日期、币种；下图仅画本次准确期限和起点对应的一个预期涨跌菱形、p10–p90竖范围（中间80%预测范围）和0%参考线。它不是K线、OHLC或连续未来净值路径，不在不同期限之间插值，也不把执行起点后的收益乘到滞后的旧净值上编造未来价格。竖范围独立于均值，均值可能落在范围之外；该范围不是均值的置信区间。

下图横轴是条件计划卖出日，不是已知的未来实际净值日，也不拿自然日截止日冒充计划卖出日。后台从实际测算日加窗口天数，按条件业务日程得到申请日、计划卖出日及准确H/L（成交后净值笔数／起点延迟）；笔数不直接叫自然日。日历缺失时采用明示的工作日情景，不承诺节假日能成交或资金到账。没有准确头、H=0或日期不完整时不补画预测；只有均值而缺少对应范围时，仅保留均值并说明缺项。缺预测但有真实净值时，历史线与其实际数据日期仍保留。

图表提供悬停数值、符号／图例，以及“图表数据（可用键盘查看）”中的同口径数据表，支持明暗主题和窄屏。历史净值不是分红再投资总回报；下图涨跌估计不含申赎费用，不是账户收益，实际结果仍可能落在范围之外。“已经持有”可另见所选假设买入日到最新实际净值的过去涨跌，它不是未来预测或个人盈亏。

### 日期费用与独立检验工具

“日期与费用设置”保留旧份额、本次新买／追加各自的模拟确认日，以及申购、当前旧份额赎回、未来旧份额赎回、未来新份额赎回四种费率。费用优先使用公示申购率和赎回阶梯，费龄从各批确认日算到相应申请日，不从净值期数推算，也不把新份额当成旧份额免赎回费。缺适用资料时保留明示的示例假设，不把未知当免费；公示费率不是支付宝等购买渠道的实际折扣。编辑确认日期后需提交控件中的值才影响计算。“记住这些设置”只保存独立设置，不新增持仓或改写旧判断。

“走势与资料”保留以下可选工具，不要求完成它们才能获得当前建议，也不靠它们直接重写已展示的建议：

- **完整研究与条件计算工具**：查看原研究、反方、候选比较、在线资料及盈利／估值等独立条件计算。
- **历史检验与卖出日期工具**：“运行历史检验”才用已有输入重建准确H/L的逐时点预测流，保留未成熟、无预测和无效窗口；按本次统一批次年龄／费用核对动作与同资本简单方法。它检验H笔实际净值，不是严格N自然日策略或当年实际渠道费率，不把重叠窗口连乘成年化，也不把今天AI研究倒填历史。
- **少量卖出时点比较**：“比较这几个卖出时点”只比较同一笔旧份额的现在申请退出、窗口内下一低费档对应开放日、原计划卖出日；重复日期合并，不提前套低费率。各未来日期分别与现在退出比较，准确预测缺失时仍可保留纯费用节省与盈亏边界。这不是必须等待指令、全局最佳日期或不同未来日期之间的胜率。
- **个人金额换算与资金工具**：可主动填写预算、费用和资金用途，查看个人金额与容量；不是当前建议的前置问卷，也不把后台标准本金当作用户持仓。当前保存的主判断不会因此自动变成个人金额报告。

这些工具中的标准净额比较仍坚持同组、同资本、同一准确头：新买与现金各一笔；已有基金组从基金一笔＋备用现金一笔开始。计划日赎回净额包含应收款，不等于截止日已到账；不重复扣净值内年费。金额比较是工具口径，不是当前主卡的展示内容或经验证的择时能力。

当前页面不再提供“预测模型”选择器，使用既有净值趋势方法；试验因素模型没有提升为日常建议入口。需要明确更新时，在“管理与更新”选择“用已保存净值更新预测”（不联网）或“更新净值与预测”（才获取免费公开来源）。试验模型、独立研究服务和旧预测记录仍保留，不因本次简化界面被删除或换成另一方法的标签。

“和上次保存相比”只读本基金最近一份原快照，当前页至多显示所选情境最相关的两条建议、主要理由、下一步或费用变化。新取得时间、新标题和新计算时间本身不等于改判；只有研究明确关联上一版本并保存变化解释，才称为对上一研究的解释。缺旧字段不补默认值，私人库不可读也不阻断当前判断。

### 保存当前建议与图，不重建旧页面

“保存这次判断”保存刚才实际展示的同一个schema7对象（mode `buyer_decision`，policy `fund_buyer_economic_advice_v3`，内嵌brief3），其中包括当时选择的`selected_branch`、用户投影`buyer_view`和最小图快照`forecast_chart`，以及原研究、条件日程、分批费用、准确预测头与模拟参照等内部依据。图快照保留实际历史点、单位／日期口径、单个预测点与内部身份；内部身份不进入日常renderer、悬停和公开图表数据表。保存不会另算一份建议，不重新拟合，不冒充正式发行，不提交买卖或新增持仓。

历史记录直接回放已保存的`buyer_view`和`forecast_chart`及当时情境。某字段或图未保存就说明缺项，不从其他分支重投影，也不用今天净值补画旧图。旧schema7 brief1／brief2继续原视图，可能仍显示当时的示例本金、备选金额差、分歧与完整情景；它们是旧快照语义，不是当前页的说明。旧schema3–6也按原口径回放：schema6保留原自然日计划和计划卖出净额，schema5保留原净值笔数与不自动赎回的账面终值；绝不以今天首选、日期、费率或新图改写。

### 明确更新研究

“重新在线检查”只更新当前事实；“更新研究”才调用你已有的模型API，读取公开正文、披露与程序计算，并生成新买、已有持仓、追加的独立理由。普通切页、改费用、保存和查看历史不调用模型API。原短期预测仍由单独的明确更新动作生成，研究不重写它的概率。

当前动作只采用研究实际记录的独立理由：新买与暂留现金相比、持有与卖出/实际候选相比、追加与保留现有投入相比，解释收益机会、代价和改判事件。持有同样承担今日风险与机会成本，不能仅因“没发现必须卖”就自动建议持有。旧v1笔记只有总倾向，当前页面保留其研究日和原文，不再由姿态词生成三份貌似独立的建议。没有生成新研究时不假装这些取舍已经完成。

当前页只展示所选情境的一句主要原因与下一步；各分支完整理由、反方和个人／执行条件在独立研究工具中分开查看。经理名单、标题、资料状态及引用核对口径不作为三个动作共用的理由。明确个人或执行约束影响最终建议时，完整对象仍保留原经济方向，便于区分基金判断与条件变化；单独编辑个人金额工具不自动改变主卡。旧快照没有新增标记时仍按原展示读取，不用新逻辑重算。

在“研究API设置”中明确选择协议、填写服务地址、实际模型名和Key。当前支持OpenAI兼容Chat Completions及Anthropic Messages，不自动猜地址或切换协议；使用原服务额度，不承诺免费无限量。Key只留本会话，或由应用专用环境变量`RMBFUND_RESEARCH_API_KEY`注入；非秘密配置可从明确的`<root>/research-api.json`读取，不搜索其他终端凭据或`.env`。API只收到公开身份、材料及研究，不收到你的份额、成本、预算或用款条件。

完整研究工具保留真实研究日、模型及“AI生成”标识，不冒称人工复核；这些研究来源细节不搬到当前建议主卡。2026-10-28的018147研究由当轮会话完成，单独标为“会话助手研究”，来源为`assistant_generated_research`，不是应用API调用。已有的新买、持有、追加研究可查看，不要求先配置API；后续通过应用生成新研究仍需明确配置已有API并点击更新。

正文摘录绑定实际URL、页/节、发布日期与取得时间；标准化数据不是发布者逐字原文。保存只保留研究采用的摘录、对应经济记录与计算依据，不要求全文归档；采用的九月底组合也用于当前画像、比较及组合穿透，而不是主文更新后仍显示六月。下次可以据此判断新报告是否改变原理由，旧版本缺失的基线不会事后补造。引用核对不代表投资结论正确；未配置、API失败或输出无法核对时不编替代建议，已完成研究保留原日期。

当前、走势与总览复用本会话同批RAM估值；新研究完成后使用该批资料重新评估，不把原取得时间改成生成时间。已有持仓时仍可从候选比较或代码入口公开预览，不加入个人持仓，也不复制份额或成本。

当前“日期与费用设置”可通过“记住这些设置”明确保留已填写的情境、日期与费用，下次继续修改；这不等于已核对当日支付宝条件，也不自动新增持仓。个人金额与资金规划另在“走势与资料”的工具中使用，可计算近期用款与容量，但不覆盖当前主判断，也不要求完整问卷才能给基金建议。基金波动与赎回非即时，QDII还涉及境内外交易日；不编到账日期。

个人金额工具分开解释当前市值与情景净额：市值按最近已公布净值估算；固定份额情景使用该头自己的日期、净值和明确币种，不假造未来执行净值。主动填写预算时才做相应金额换算，未知费用或条件不合法时不显示为可执行净额；没有预算不推测投入。新brief3主卡和保存图不展示这些金额，旧快照或明确打开的个人工具仍可保留原有金额语义。

### 资料更新、替代选择和金额工具

在线当前判断与命令行的`followed-refresh`不同：前者在当前标签从动态公开列表直接取得并在内存使用，后者仍是显式留存／复核历史资料的工具。消息的来源、日期、标题／摘要／正文摘录状态和关联理由可在“走势与资料”的完整研究工具核对，不以来源状态表占据当前主卡。仅标题或未解析文件不自动变成买卖信号；在线结构化操作条件可进入执行判断，但不改作者研究日期、短期概率或历史快照。失败或停止来源不把旧资料续鲜成今日消息。

`followed-refresh`和`followed-review-retained`保留为明确的历史留存/复核命令，不再作为日常当前消息的前置步骤；当前页面不需要操作这一归档流程。基金没有已核对的研究映射时如实显示未覆盖，不套用别的基金笔记。

同类比较逐一保存关系与选取理由。同一底层A/C是成本替代，不是分散化；不同授权的主题基金说明得失，不编综合排名。共同日期不同就分组看，无分红/拆分覆盖只称单位净值变化。换基须考虑赎回、现金可用、申购及完整费用，不相减两个预测冒充换仓收益。

组合分母是**已记录且能估值的人民币基金市值**，不是个人总资产。发行人暴露按市值乘披露NAV权重，重合只按明确issuer_id；展示披露/估值日、覆盖及未知，不把剩余部分叫现金，也不把公司与行业切面相加。

可选输入现金、最高投入、损失预算、整基金压力跌幅及资金用途；默认只计算所选基金子仓。也可选择已记录全部人民币基金，在**同一个情景**为每只基金填涨跌；任一基金估值或情景未知时，不计算完整组合上限。不能拼接各基金独立预测分位数。

同一情景已有损失`L0`、预算`B`、新增目标基金变动`d`、外扣申购费`f`时，损失系数`k=1-(1+d)/(1+f)`。仅`k>0`时新增上限为`max(0,B-L0)/k`再与现金和明确限制取小。减少毛额`x`后的损失为`L0-x*(-d-r)`；仅`-d>r`才有情景损失改善。超出现有市值或限制时明确不可行；市值只是可售上界，不是渠道可赎资格。容量不等于建议用满，也不因`k<=0`称无风险。

买入预演区分含费现金与实际入基金金额，赎回预演区分毛额与净款；只按最近净值静态展示比例，不改份额、不记录订单。没有个人条件仍可看基金判断，不强制问卷。

旧NAV v1/v2是同一算法家族；经验分布是回退或比较基准，不另凑日常选项。盈利、估值、经理评论不冒称已经入模：独立条件工具可自行填写盈利／估值或行业价格变化，空白不计算、不赋概率，也不改变基础预测或当前最终建议。旧快照中已经保存的条件计算照原样回放；当前“保存这次判断”不自动收集另一工具尚未纳入主判断的输入。
